# Финансы

Учёт доходов, расходов, долгов и платежей — одностраничное веб-приложение
на чистом JS без сборщика. Русский интерфейс, тенге, мобильный экран основной.

**Живёт здесь: https://finance-anuar.web.app** (Firebase Hosting, ставится на
телефон как приложение; данные — Firestore, вход через Google).

## Что где

| Путь | Что это |
|---|---|
| `index.html` | всё приложение: стили, разметка, логика. Это **тело страницы**, без тегов `<html>/<head>/<body>` — их добавляет сборка |
| `CLAUDE.md` | контекст проекта: модель данных, дизайн-система, соглашения |
| `web/` | всё, что нужно для веб-версии: адаптер Firebase, правила доступа, иконки, [инструкция](web/README.md) |
| `docs/` | собранная страница, которая выкладывается. Не исходник — правится только пересборкой |
| `dev/build.js` | собирает `dev/test.html` для запуска в обычном браузере |
| `dev/shim.js` | заглушка облачной базы, данные в памяти |
| `dev/build-web.js` | собирает `docs/` |
| `tests/smoke.js` | прогон по всем вкладкам через Playwright |

## Разработка

```bash
npm i                   # один раз
npm test                # собрать dev/test.html и прогнать сценарии
```

Затем открыть `dev/test.html` в браузере — там база в памяти, данные живут до
перезагрузки страницы.

## Выкладка

```bash
npm run deploy          # пересобрать docs/ и выложить сайт с правилами Firestore
```

Требует однократного `npx firebase login`. Подробности и первичная настройка —
в [web/README.md](web/README.md).

## История

Приложение начиналось как артефакт Claude под именем «Гроссбух»
(`https://claude.ai/code/artifact/f7c1e768-ebfa-4fad-a6b8-a543b3d1c619`). Тот адрес
ещё работает и показывает старую версию; `index.html` не знает, где он запущен,
поэтому при желании публикуется и туда.
